# FocusTV AI 
> An intelligent, age-agnostic AI study assistant designed for large TV screens.

FocusTV AI helps students of all age groups learn dynamically. When a student asks a question, FocusTV uses Google's **Gemini 2.5 Flash** to generate a concise, easy-to-read explanation alongside a dynamic educational video stream.

---

##  Features
*  **Generative Explanations:** Powered by Gemini 2.5 Flash API to deliver concise study answers tailored for TV viewing.
*  **Smart Video Integration:** Dynamically maps queries to reliable educational video streams.
*  **Fast Flask Backend:** Lightweight Python server routing requests seamlessly.

---

## Tech Stack
* **Backend:** Python, Flask
* **AI Model:** Google Gemini 2.5 Flash (`google-genai`)
* **Frontend:** HTML5, CSS3, JavaScript
